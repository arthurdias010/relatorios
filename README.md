# Relatórios de Sistemas Web — 2º D

Repositório destinado ao armazenamento e à organização dos relatórios desenvolvidos pelos alunos do **2º D do curso Técnico em Informática para Internet**, da **ETEC Vasco Antonio Venchiarutti**, para a disciplina de **Sistemas Web (SWEB)**.

## 📚 Sobre o repositório

Este repositório reúne os relatórios produzidos pelos alunos durante as atividades da disciplina, documentando pesquisas, projetos, sistemas desenvolvidos e outros conteúdos relacionados aos temas estudados.

O objetivo é centralizar os documentos em um único local, facilitando o acesso, a consulta e o compartilhamento dos trabalhos realizados pela turma.

## 📁 Organização dos arquivos

Os relatórios são organizados em arquivos e pastas de acordo com os trabalhos apresentados pelos alunos.

Cada documento corresponde a um relatório elaborado no contexto das atividades da disciplina.

## 🎯 Objetivos

- Centralizar os relatórios da turma em um único repositório.
- Facilitar a consulta aos trabalhos desenvolvidos pelos alunos.
- Organizar a documentação das atividades da disciplina.
